Βάλε εδώ τις φωτογραφίες background με ΑΚΡΙΒΩΣ αυτά τα ονόματα (JPG):

  hero.jpg      -> πάνω-πάνω (hero), πίσω από τα ονόματα. Ιδανικά οριζόντια, φωτεινή.
  details.jpg   -> πίσω από τις κάρτες (τελετή / δεξίωση).
  rsvp.jpg      -> πίσω από τη φόρμα RSVP.
  footer.jpg    -> πίσω από το footer.

Οδηγίες:
- Μορφή: .jpg, ονόματα με μικρά γράμματα, χωρίς κενά/τόνους (ακριβώς όπως πάνω).
- Προτεινόμενο πλάτος ~1600-2000px, συμπιεσμένες (<~500KB η καθεμία) για γρήγορο φόρτωμα.
- Το overlay είναι απαλό, οπότε προτίμησε φωτογραφίες χωρίς πολλά σκούρα σημεία για να διαβάζονται τα κείμενα.
- Αν ΔΕΝ βάλεις κάποια εικόνα, απλώς μένει το κρεμ gradient εκεί — δεν χαλάει τίποτα.
- Θες κι άλλο/λιγότερο; Οι αντιστοιχίσεις είναι στο styles.css (κλάση .bg-photo). Για να προσθέσεις section, βάλε class="... bg-photo" + <div class="section-inner"> και αντίστοιχο κανόνα στο CSS.

Μετά: commit + push από το VM (όπως οι άλλες αλλαγές) και το GitHub Pages ανεβάζει αυτόματα.
